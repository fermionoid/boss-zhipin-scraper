# Boss直聘沟通页候选人批量抓取工具

给招聘账号持有人自用的工具：通过 CDP 接管本人已登录的浏览器，遍历 Boss直聘
网页版「沟通」页会话列表，把候选人信息（姓名/学历/学校/年限/期望等）整理成
CSV 表格并逐人截图存档。仅用于账号持有人自己的正常招聘业务，数据不外传。

工程复盘：[为什么最终用浏览器书签而不是程序接管浏览器](POSTMORTEM.md)

## 使用（推荐：下载 Release 完整包）

源码仓库**不含** Python 运行时（`python/` 目录，约 130MB），直接 clone 跑不起来。
请到 [Releases](../../releases) 下载 `boss抓取工具_*.zip` 完整包，解压后：

1. 双击 `1_启动浏览器.bat`，在弹出的浏览器里扫码登录 Boss直聘，停在「沟通」页
2. 双击 `2_开始抓取.bat`，等黑窗口跑完，结果在 `输出/` 文件夹

详细步骤见包内 `使用说明.txt`；让 AI 助手（WorkBuddy/Kimi 等）接管运行和排错
见 `AI操作手册.md`。

## 结构

- `scraper/config.py` — 所有 CSS selector、正则、黑名单、参数（页面改版只改这里）
- `scraper/main.py` — 主逻辑：CDP attach、虚拟列表遍历、断点续传、防风控节奏、
  验证码暂停、recommend 卡死页拉回、诊断包自动生成
- `输出/debug/` — 每次运行自动生成诊断报告（selector 体检表 + DOM 快照 + 截图）
