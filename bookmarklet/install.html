候选人收集器 · 安装（只需做一次）

第一步：把下面这个绿色按钮拖到收藏栏

如果看不到收藏栏，先按 Ctrl + Shift + B 把它显示出来。

📋 收集候选人

用鼠标按住绿色按钮，拖到浏览器上方的收藏栏松手即可。
不要点它，这里点了没用——要拖。

第二步：以后每次这样用

  1. 用你平时的浏览器打开 Boss直聘，登录好
  2. 进入「沟通」页面，左侧能看到候选人列表
  3. 点一下收藏栏里的「📋 收集候选人」
  4. 右下角会出现小面板，点「开始」，然后就不用管了
  5. 跑完点「导出表格」，会下载一个 候选人.csv，用 Excel 打开
说明
· 中途可以随时点「停止」，已收集的不会丢；下次点「开始」接着来
· 关掉网页也没关系，进度存在浏览器里，重新打开点「开始」继续
· 收集过程中不要手动点左侧的会话，让它自己点
· 有问题就把右下角小面板的文字拍给我
